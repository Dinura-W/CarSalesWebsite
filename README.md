# 🚗 CarSalesWeb

A modern car marketplace web application built using ASP.NET Core MVC.  
Users can browse, search, and list vehicles for sale, complete with image uploads and detailed vehicle information.

This project was built to practice full-stack web development concepts including MVC architecture, database integration, file uploads, and responsive UI design.

---

## 📌 Overview

CarSalesWeb is a dynamic vehicle marketplace that allows users to:

- View available cars
- Search and sort listings
- View detailed car information
- Upload and list their own vehicles
- Store car images locally
- Interact with a clean, modern UI

The project focuses on building a real-world CRUD application using ASP.NET Core MVC and Entity Framework.

## 🏗 Architecture

This project follows the MVC (Model-View-Controller) pattern:

- **Models** → Represent Car entities and database structure  
- **Views** → Razor pages that render dynamic content  
- **Controllers** → Handle user requests, filtering, sorting, and data flow  

Entity Framework Core handles database operations and LINQ is used for querying and filtering.
